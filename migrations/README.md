# 迁移约定

一条迁移 = 一个 `YYYYMMDDHHMMSS-短描述.sh` 文件，权限 `0644`，不带 shebang。
runner 使用 `bash -euo pipefail` 执行，工作目录为仓库根，另提供 `MYCONFIG_REPO`；测试里可用同名环境变量把仓库指到临时目录。
必须幂等：先查现状再动手；文件不存在时打印说明并正常退出。
只删除内容与仓库退役版本一致的路径，必须用 sha256 守卫。
内容不确定就 skip 并打印，绝不删除用户手写的东西。
迁移严格按文件名顺序、同步执行；失败必须 exit 非 0，让后续迁移停住。
需要 sudo、systemctl 或图形会话重载的步骤只打印命令，交给用户手动执行，迁移不得自动调用。
成功记录在状态目录；可用 `MYCONFIG_STATE_DIR` 覆盖整个路径以隔离测试。
应用时用状态目录下的 `.lock` 目录拒绝并发运行；marker 通过临时文件原子替换。
若进程被 SIGKILL 或断电中断，确认没有 runner 在运行后手动删除空的 `.lock` 目录再重试。
